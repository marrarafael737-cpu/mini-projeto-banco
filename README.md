# Mini Projeto Banco

Projeto de console desenvolvido em C# com .NET 10 para praticar conceitos básicos de programação.

## Funcionalidades

- Login com limite de tentativas
- Saque
- Depósito
- Consulta de saldo
- Encerramento do programa

## Como executar

Pré-requisito: SDK do .NET 10 instalado.

```powershell
dotnet run --project "mini projeto banco\mini projeto banco.csproj"
```

Este é um projeto pessoal de estudo e será evoluído conforme novos conceitos forem aprendidos.
